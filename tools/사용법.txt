CKP Manual Report - 공식 11종 생성 폴더
==========================================================

■ 처음 한 번 (새 PC 에 깔 때)

   1) 이 폴더를 C:\CKP-Report 에 두세요.
      바탕화면·내문서·OneDrive 안은 피하세요. 경로에 한글이나 공백이 있으면
      지갑을 못 읽습니다. (프로그램이 실행할 때 이 점을 검사해 알려 줍니다.)

   2) OCI 지갑 zip 을 wallet\ 폴더에 넣으세요.
      압축을 풀어 넣어도 되고, zip 째 넣어 두어도 알아서 풉니다.

   3) setup.bat 을 실행하세요. 이것 하나로 준비가 끝납니다.
        · 필요한 라이브러리를 vendor\ 에서 인터넷 없이 설치
        · 지갑을 찾아 sqlnet.ora 를 이 PC 경로로 자동 수정
        · DB 계정 / DB 비밀번호 / 지갑 비밀번호를 물어봄  ← 담당자에게 받은 값
        · 방화벽이 뚫려 있는지 확인하고, 실제로 한 번 접속해 봄

      비밀번호는 배포 zip 에 들어 있지 않습니다. 여기서 입력한 값이
      이 PC 의 ckp_reports\config.ini 에만 저장됩니다.
      나중에 바꾸려면 setup.bat 을 다시 실행하면 됩니다.


■ 평소 쓰는 법

   run.bat  더블클릭  →  기준 날짜 입력(그냥 Enter 면 오늘)  →  끝

   결과는  report\CKP_official\기준<날짜>_요청<날짜>\  안에 엑셀 11개로 저장됩니다.
   폴더 위치는 끝날 때 화면에 그대로 찍힙니다.


■ DB 가 잘 붙는지만 보고 싶을 때

   check.bat  더블클릭   (몇 초, 리포트는 만들지 않음)

   어느 경로로 붙었는지, 방화벽이 열려 있는지, 데이터가 며칠까지 들어와 있는지
   알려 줍니다. 리포트가 이상할 때 'DB 문제인지 프로그램 문제인지' 를 먼저
   가르는 용도입니다.

   ※ 우리가 보는 DB 는 원장의 복사본입니다. 최근 며칠 데이터가 없는 것은
      고장이 아니라 정상입니다. 기준 날짜를 check.bat 이 알려주는
      '최신 스캔일' 이전으로 잡으면 데이터가 정상적으로 나옵니다.


■ Claude 로 시키고 싶을 때 (선택)

   connect_claude.bat 을 한 번 실행 → Claude 를 완전히 껐다 켜기
   → 스킬 파일(.skill)을 Claude 에 올리기
   → 채팅창에 "레포트 11개 작성해줘"

   이 배치는 Claude 설정 파일에 '이 폴더의 현재 위치' 를 적어 줍니다.
   폴더를 옮겼다면 옮긴 자리에서 한 번 더 실행하세요.
   Claude 를 안 쓰고 run.bat 만 써도 리포트는 똑같이 나옵니다.


■ 파이썬

   PC 에 설치된 파이썬 3 을 씁니다. 없으면 run.bat 이 알려 줍니다.
   ( https://www.python.org/downloads/ 에서 설치, "Add python.exe to PATH" 체크 )


■ 폴더 구조

   run.bat                리포트 생성 (평소 쓰는 것)
   setup.bat              최초 1회 준비 / 설정을 바꿀 때
   check.bat              DB 연결만 빠르게 점검
   connect_claude.bat     Claude 에 이 폴더를 연결 (선택)
   wallet\                OCI 지갑을 여기에
   vendor\                오프라인 설치용 라이브러리 - 건드리지 마세요
   ckp_reports\config.ini 설정 파일 (setup.bat 이 만들고 채웁니다)
   report\CKP_official\   결과 엑셀이 쌓이는 곳
   tools\                 실행 도우미 - 건드리지 마세요


■ 잘 안 될 때

   check.bat 을 실행하면 원인을 한 줄로 짚어 줍니다. 대부분 아래 다섯입니다.

   · 지갑이 wallet\ 폴더에 없다
   · DB 비밀번호가 비었거나 틀렸다          (ORA-01017)
   · 지갑 비밀번호가 비었거나 틀렸다        (지갑을 못 엶)
   · 폴더 경로에 한글이나 공백이 있다       (ORA-12154 / ORA-17956)
   · 사내 방화벽이 DB 포트를 막고 있다      (연결 시간 초과)
     → IT 담당에게 'adb.ap-chuncheon-1.oraclecloud.com 1522 아웃바운드 허용' 요청

   화면에 나온 메시지를 그대로 담당자에게 보내 주시면 됩니다.
