CKP Manual Report — 공식 11종 생성 폴더
==========================================================

폴더 안에 이것만 있습니다.

   CKP.bat      ← 실행할 것은 이 하나뿐입니다
   wallet\      ← OCI 지갑을 여기에 넣으세요
   report\      ← 결과 엑셀이 쌓입니다 (자동으로 생깁니다)
   program\     ← 프로그램 본체. 열어볼 일 없습니다
   사용법.txt   ← 이 파일


■ CKP.bat 을 누르면 나오는 메뉴

   1. 리포트 만들기 (엑셀 11개)      ← 평소에는 이것만
   2. 처음 설정 / 설정 바꾸기        ← 새 PC 에서 맨 처음 한 번
   3. DB 연결만 점검                 ← 뭔가 이상할 때
   4. Claude 에 이 폴더 연결         ← 스킬로 시키고 싶을 때만


■ 새 PC 에 처음 깔 때 (3분)

   1) 이 폴더를 C:\CKP-Report 에 두세요.
      바탕화면·내문서·OneDrive 안은 피하세요. 경로에 한글이나 공백이 있으면
      지갑을 못 읽습니다. (프로그램이 알아서 검사해 알려 줍니다.)

   2) OCI 지갑 zip 을 wallet\ 폴더에 넣으세요.
      압축을 풀어 넣어도 되고, zip 째 넣어 두어도 알아서 풉니다.

   3) CKP.bat → 2 번.
        · 필요한 라이브러리 설치 (vendor 가 있으면 인터넷 없이)
        · 지갑을 찾아 그 PC 경로에 맞게 자동 수정
        · DB 계정 / DB 비밀번호 / 지갑 비밀번호를 물어봄  ← 담당자에게 받은 값
        · 방화벽이 뚫려 있는지 확인하고 실제로 한 번 접속해 봄

      비밀번호는 배포 파일에 들어 있지 않습니다. 여기서 입력한 값이
      이 PC 안에만 저장됩니다. 바꾸려면 2 번을 다시 실행하면 됩니다.

   4) CKP.bat → 1 번. 날짜를 묻습니다(그냥 Enter 면 오늘).


■ 결과는 어디에

   report\CKP_official\기준<날짜>_요청<날짜>\  안에 엑셀 11개.
   끝날 때 화면에 경로가 그대로 찍힙니다.


■ 데이터가 비어 보일 때

   우리가 보는 DB 는 원장의 복사본입니다. 최근 며칠이 없는 것은
   고장이 아니라 정상입니다. 3 번을 실행하면 '최신 스캔일' 을 알려 주니,
   기준 날짜를 그 날짜 이전으로 잡으면 정상적으로 나옵니다.


■ Claude 로 시키고 싶을 때 (선택)

   CKP.bat → 4 번 → Claude 를 완전히 껐다 켜기
   → 스킬 파일(.skill)을 Claude 에 올리기
   → 채팅창에 "레포트 11개 작성해줘"

   4 번은 Claude 설정에 '이 폴더의 현재 위치' 를 적어 줍니다.
   폴더를 옮겼다면 옮긴 자리에서 4 번을 한 번 더 실행하세요.
   Claude 를 안 써도 1 번만으로 리포트는 똑같이 나옵니다.


■ 날짜 기준

   기준일은 이 PC 가 있는 지역의 '오늘' 입니다. 실행하면 첫 줄에 이렇게 찍힙니다.

      [time] 기준 시계: WIB (UTC+7) - 이 PC 의 시간대 · 지금 2026-07-29 08:10

   한국 기준으로 고정하고 싶으면 program\ckp_reports\config.ini 에서
      site_timezone = Asia/Seoul
   로 바꾸면 됩니다 (기본값 auto = 이 PC 를 따름).

   PC 시계가 실제 시각과 많이 어긋나 있으면 실행할 때 경고가 나옵니다.


■ 파이썬

   PC 에 설치된 64비트 파이썬 3.11 ~ 3.14 를 씁니다. 3.12 를 권합니다.
   없거나 버전이 안 맞으면 화면이 그렇게 알려 줍니다.
   ( https://www.python.org/downloads/ — "Add python.exe to PATH" 체크 )


■ 잘 안 될 때

   3 번을 실행하면 원인을 한 줄로 짚어 줍니다. 대부분 아래 다섯입니다.

   · 지갑이 wallet\ 폴더에 없다
   · DB 비밀번호가 비었거나 틀렸다          (ORA-01017)
   · 지갑 비밀번호가 비었거나 틀렸다
   · 폴더 경로에 한글이나 공백이 있다       (ORA-12154 / ORA-17956)
   · 사내 방화벽이 DB 포트를 막고 있다      (연결 시간 초과)
     → IT 담당에게 'adb.ap-chuncheon-1.oraclecloud.com 1522 아웃바운드 허용' 요청

   화면에 나온 메시지를 그대로 담당자에게 보내 주시면 됩니다.
